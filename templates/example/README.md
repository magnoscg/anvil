# Example Feature

The Example feature is not a separate set of templates. It is generated by calling
`FeatureScaffolder.Scaffold()` with `FeatureConfig{FeatureName: "Example"}`.

## How It Works

When the user selects "Include Example Feature" during `anvil init`, the generator
code (phase 14) checks `cfg.IncludeExample`. If `true`, it invokes the same
feature scaffolding logic used by `anvil feature <name>`, but with the name
hard-coded to `"Example"`.

This produces the full feature structure:

```
Domain/Example/
  Models/ExampleModel.swift
  UseCases/ExampleUseCase.swift
  UseCases/ExampleUseCaseImpl.swift

Data/Example/
  Repositories/ExampleRepository.swift
  Repositories/ExampleRepositoryImpl.swift
  DataSources/ExampleRemoteDataSource.swift
  DTO/ExampleDTO.swift
  Mappers/ExampleDTOMapper.swift

Features/Example/
  DI/ExampleFactory.swift
  UI/ExampleView.swift
  UI/ExampleState.swift
  UI/ExampleDecorator.swift
  Presentation/ViewModels/ExampleViewModel.swift
  Presentation/Mappers/ExampleDecoratorMapper.swift
  Navigation/ExampleRouter.swift

Tests/Domain/Example/UseCases/ExampleUseCaseImplTests.swift
Tests/Data/Example/Repositories/ExampleRepositoryImplTests.swift
Tests/Data/Example/Mappers/ExampleDTOMapperImplTests.swift
Tests/Features/Example/Presentation/ViewModels/ExampleViewModelTests.swift
Tests/Features/Example/Presentation/Mappers/ExampleDecoratorMapperImplTests.swift
Tests/Mocks/ExampleRepositoryMock.swift
Tests/Mocks/ExampleUseCaseMock.swift
Tests/Mocks/ExampleRemoteDataSourceMock.swift
Tests/Mocks/ExampleDecoratorMapperMock.swift
Tests/Mocks/ExampleDTOMapperMock.swift
Tests/Mocks/ExampleRouterMock.swift
```

## No Duplicate Templates

All templates live in `templates/feature/`. The Example feature reuses them
entirely. There is no need to maintain a separate copy of templates for the
example -- this avoids drift and duplication.
